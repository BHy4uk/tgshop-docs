## Reply-клавіатура бота

Джерело: `backend/app/bot/keyboards.py` → `main_menu_reply_keyboard`.

Для звичайного покупця: `🏠 Старт`, `🗂 Каталог`

Для адміністратора додається другий ряд:
`⚙️ Admin`, `📦 Товари`, `📑 Замовлення`

Для платформного адміна ще один ряд: `🛠 Платформа (admin)`

> Увага: у reply-клавіатурі замовлення позначені `📑`, а в інлайн-меню — `📋`.
> Це не помилка документації, так у продукті.

| Внутрішнє значення | Назва в налаштуваннях |
|---|---|
| `liqpay` | `LiqPay` |

Що бачить покупець на checkout:
`💳 Оплатити онлайн через LiqPay`, `💳 Оплатити онлайн через Monobank`,
`💳 Онлайн оплата`, `🏦 Банківські реквізити` (badge `IBAN`),
`📦 Накладений платіж`, кнопка `Я оплатив(ла)`.

## Режими залишків

| Режим | Назва в інтерфейсі |
|---|---|
| `tracked` | `Відстежувати залишки` |
| `untracked` | `Без ліміту залишку` |

Поняття: `stock` — фактичний залишок, `reserved` — резерв під незавершені
замовлення.

**Правило:** для `untracked` товару має бути увімкнена хоча б одна
онлайн-оплата (`LiqPay`, `plata by mono`, `Оплата за посиланням`,
`Оплата за реквізитами`). Інакше checkout для нього блокується.

## Форма товару

Поля: назва, опис, ціна (грн), категорія, режим залишків, назва опції
(плейсхолдер `Розмір / Колір / Вага`), варіанти, фото (до 5),
чекбокс `Активний у каталозі`, кнопка `Зберегти та додати товар`.

## Нова пошта

Картка **Нова пошта** в секції `Доставка`.

Поля і кнопки, дослівно:
`API ключ`, `Зберегти API ключ`, `Місто відправника`, `Знайти місто`,
`Точка відправлення`, `Знайти точку відправлення`, `ПІБ відправника`,
`Телефон відправника`, `Скинути налаштування`, `Зберегти доставку`.

Умови створення ТТН без помилки: увімкнений модуль, збережений API ключ,
заповнені дані відправника, у замовленні є дані отримувача та Nova Poshta
refs для міста і відділення.

## Режими доступу магазину

Джерело: `backend/webapp/admin_products/index.html`.

| Значення | Назва | Що означає |
|---|---|---|
| `auto` | `За статусом підписки` | Доступ визначається поточною підпискою |
| — | `Працює у звичайному режимі` | Магазин примусово активний |
| `soft_freeze` | `Пауза checkout` | Перегляд доступний, нові замовлення не оформлюються |
| `frozen` | `Магазин приховано для клієнтів` | Вітрина тимчасово недоступна |
